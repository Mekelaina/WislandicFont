
# Wislandic: a font introduction

## Welhhase, autlhaki! </br> 

Wislandic is a font I created to type the script of the conlang, Wislandic, for a novel I am working on. Known in universe as Wistunner by it’s speakers, the conlang is still in development, however the writing system, known as Wisskel is mostly done. Below you will find a breakdown of the font and of how to type Wislandic. But before that, I should explain the phonology of Wislandic briefly so the font makes a bit more sense.
